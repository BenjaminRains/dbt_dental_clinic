# Archive

Historical material. ETL, dbt, the API, and the frontend do not read these folders.

| Path | What it was |
|------|-------------|
| `analysis/` | OpenDental table notes and DDL captured while the dbt models were first written (spring 2025). Current validation lives in `dbt_dental_models/validation/`. |
| `analysis_intermediate/` | Intermediate-model scratch from the same period (grain notes, notebooks, sample extracts). |
| `stakeholders/` | April 2025 data-quality notes written for clinic staff. |

`analysis_intermediate/` was archived with `analysis/` because it is the same early modeling work, not a live input to dbt.
